# Мост знаний

Браузерная игра для начальной школы. В игре 15 тем и 38 824 уникальных задания. Каждый правильный ответ добавляет одну секцию моста. Когда мост готов, школьный автобус переезжает на другой берег, а игрок видит, сколько примеров решил с первой попытки.

Это самостоятельная реализация игры по [предоставленному видеопримеру](demo/most-znaniy.mp4). Иллюстрации и программный код созданы для этой версии.

## Запуск на компьютере

Распакуйте архив и откройте файл **index.html** в браузере. Игра работает без интернета. Устанавливать программы или запускать сервер не требуется.

## Публикация на GitHub Pages

1. Войдите в GitHub и [создайте репозиторий](https://github.com/new). Можно назвать его **most-znaniy**. Для публикации с бесплатной учётной записи выберите **Public**.
2. Откройте репозиторий и нажмите **Add file → Upload files**. В пустом репозитории нажмите **uploading an existing file**. Перетащите файлы и папку **demo** из распакованного проекта. Файл **index.html** должен оказаться в корне репозитория. Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. Если ваша основная ветка называется иначе, выберите её. Нажмите **Save**.
4. Дождитесь публикации. На странице **Settings → Pages** появится ссылка на игру. Её можно отправить ученикам.

[Настройка GitHub Pages в документации GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Как играть

Выберите тему и длину раунда — 5, 10 или 15 заданий. Для сложения и вычитания можно выбрать отдельное действие. Для умножения и деления доступны тренировка одной таблицы от 2 до 9, смешанная таблица и испытание мастера.

В заданиях с числовым ответом используйте экранную или обычную клавиатуру. В сравнениях выберите знак **<**, **=** или **>**. Нажмите **Проверить** или **Enter**. После ошибки можно исправить ответ и продолжить игру. Звук и анимацию можно переключить в верхней панели.

## Оформление игры

На экране **Выбери маршрут** открой блок **Оформление игры**. Выбери один из четырёх фонов — горы, лесную реку, зиму или звёздную ночь — и цвет машинки. Доступны жёлтая, красная, синяя, зелёная, фиолетовая и розовая машинки.

Миниатюры показывают каждый фон, а большая картинка сразу отображает выбранное сочетание. Оно используется на главной странице, во время игры и на экране результата. Фон и цвет сохраняются автоматически в том же браузере, если ему доступно локальное хранилище.

## Как исключаются повторы

Игра записывает каждое показанное задание в историю браузера. Следующие раунды пропускают его, включая случаи, когда оно встречается в другой теме или другом режиме. История сохраняется после перезагрузки страницы и закрытия браузера. Если выйти из незавершённого раунда, в истории остаются только уже показанные задания.

На экране настройки видно количество оставшихся заданий. Если их меньше выбранной длины раунда, мост строится из оставшегося количества. После исчерпания набора игра предлагает другую тему или кнопку **Пройти набор заново** с подтверждением. Автоматического сброса истории нет.

История начинает записываться в этой версии игры. Она хранится на текущем устройстве в текущем браузере для адреса игры. Другой браузер, другой адрес или очистка данных сайта создадут новую историю. При локальном запуске хранение также зависит от поддержки браузером файловых страниц. Если сохранение отключено, игра покажет уведомление и будет помнить задания до закрытия страницы.

## Обновление существующей публикации

Замените файлы в репозитории содержимым нового архива, включая **topics.js**, **banks-reasoning.js** и **banks-applied.js**. Сохраните изменения и дождитесь обновления GitHub Pages. Откройте игру по прежнему адресу.
